# 世界大學排名戰情儀表板（QS ／ THE）· 2026-10-20 版

國立臺灣科技大學（Taiwan Tech）整合 QS World University Rankings（2023–2027）與 THE World University Rankings（2022–2027）的互動式儀表板。

**製作人**：國立臺灣科技大學 永續發展與校務研究中心　林冠宇

## 本版更新（相較 2026-10-08 版）

- **QS 總分重算**：QS 每年只公布前約 500–700 名的總分，其後只公布區間（如 601–650），過去這些學校沒有計算名次。本版依各年版官方權重，以指標分數加權重算總分。
  - 有官方總分的學校，名次不變。
  - 未公布總分的學校，在官方區間內依重算分數排序，一律落在官方區間內；估計總分以「≈」標示。
  - 驗證結果：重算加權和與已公布總分線性對應，誤差 ≤ 0.11 分；共補上 4,322 筆學校年度。
- **方法學獨立分頁**：新增「📘 方法學 Methodology」分頁。
  - QS 10 項指標、THE 18 項子指標，各列出衡量內容、資料來源與計算公式。
  - 整理自 QS 與 THE 官方方法學說明。
  - 網址加上 `#methodology` 可直接開啟此分頁。
- 移除方法學中的「校名跨年對照」說明。校名對照結果仍另附於 Excel。

## 上傳 GitHub Pages

將 `index.html` 與 `README.md` 放到儲存庫根目錄，在 **Settings → Pages** 選擇分支與 `/ (root)` 即可。

## 資料來源與計算方式

詳見網頁「方法學 Methodology」分頁。

官方公告名次可能因四捨五入、區間分組或並列而與計算名次略有差異，正式引用請以官方公告為準。
