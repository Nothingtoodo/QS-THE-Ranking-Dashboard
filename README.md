# 世界大學排名戰情儀表板（QS ／ THE）

國立臺灣科技大學（Taiwan Tech）整合 QS World University Rankings（2023–2027）與 THE World University Rankings（2022–2027）的互動式儀表板。

**製作人**：國立臺灣科技大學 永續發展與校務研究中心　林冠宇

完整的資料來源、校名對照、名次計算方式與驗證結果，請見網頁最下方「方法學 Methodology」。

## 功能

- 切換排名系統（QS／THE）與年度，搜尋任一學校（支援歷年不同校名寫法）
- 勾選最多 8 所學校，比較歷年排名趨勢與各項指標
- 單校指標趨勢：選任一學校，檢視每個子項目的歷年名次／分數走勢
- THE 同儕 50 校分組快篩、臺灣學校快篩
- 白天／黑夜模式切換

## 使用方式

單一檔案 `index.html`，資料已內嵌，不需安裝或連線到其他伺服器：

- 直接用瀏覽器開啟 `index.html`；或
- 上傳到 GitHub 儲存庫後，在 **Settings → Pages** 選擇分支與根目錄（`/ (root)`）啟用 GitHub Pages。

## 資料來源與計算方式

- **QS**：QS World University Rankings 2023–2027。2023 年與 2024–2027 年資料來源格式不同，校名已跨年對照合併。
- **THE**：Times Higher Education World University Rankings 2022–2027（官方 JSON 資料，含各構面官方名次）。學校以 THE 官方內部 ID 辨識。
- **計算名次**：依當年各校分數，以標準競賽排名法重新排序，供跨校比較使用。
  - THE 自 2024 年（WUR 3.0）起，總分為依官方權重由五大構面重算，名次為其全球位置。
  - THE 2022–2023 年官方總分僅以區間公布，取區間中點計算，名次為近似值。
- 官方公告名次可能因四捨五入、區間分組或並列而與計算名次略有差異，請以官方公告為準。
